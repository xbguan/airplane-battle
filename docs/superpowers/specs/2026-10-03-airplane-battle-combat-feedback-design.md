# 《飞机大战》战斗反馈增强设计

## 目标

在不改变激光伤害、武器等级上限、导弹伤害、敌方伤害、碰撞或背景逻辑的前提下，提升激光发射辨识度、蓝白 BOSS 能量弹可读性、双方受损反馈和导弹听觉反馈。

## 激光枪

- 保留锁定目标、充能后瞬发的攻击模型。
- 发射间隔由 2 秒调整为 1.5 秒；单发伤害和最高三级不变。
- 激光短闪时长由 0.14 秒提高到 0.18 秒，光束绘制宽度由 24 像素提高到 34 像素；锁定提示和命中逻辑不变。

## 蓝白 BOSS 能量弹素材

- 修改既有 `assets/weapons/boss-blue-bolt.png`，不新增文件或改变素材键名。
- 调整为暖白核心、靛蓝外圈、紫蓝拖尾与深色像素描边，保持透明背景与现有 2.5D 卡通像素风。
- 在实施前，先于《全部资产清单》中标注“蓝白 BOSS 能量弹（调整版）”，由用户确认素材后才替换实际 PNG 并开发游戏代码。

## 损伤反馈

- 玩家与 BOSS 按各自最大生命的比例共用两档状态：低于 65% 时显示少量灰烟；低于 35% 时同时显示橙红火苗与较浓灰烟。
- 烟火视觉由现有 Canvas 绘制和受控粒子数组生成，固定最大数量、低频产生、随角色位置移动并在生命结束时清理。
- 仅在游戏运行中显示；不会改变角色位置、碰撞半径、无敌时间、生命扣减、得分或武器规则。

## 导弹声效

- 导弹发射时播放一次短促点火音；每一枚存活导弹在飞行中拥有一个低音量推进尾音。
- 导弹飞行音与该导弹 ID 绑定，在命中、出界或寿命结束时立即停止并断开音频节点。
- 所有声音继续使用 Web Audio 合成，无音频文件、在线资源或高频重复创建；已有 BOSS、激光和机枪声不变。

## 文件范围

- 修改 `全部资产清单.html`：先登记蓝白 BOSS 能量弹调整说明，等待用户确认。
- 修改 `assets/weapons/boss-blue-bolt.png`：仅在素材确认后更新。
- 修改 `index.html`：激光节奏/闪击视觉、损伤粒子、导弹声效生命周期。
- 修改 `tests/game-logic.test.mjs`：新增激光间隔、光束视觉、能量弹引用、损伤阈值和导弹音频释放契约。
- 更新 `docs/CHANGELOG.md`；不修改 V1，不执行 Git 操作。

## 验收

1. 先加入测试并确认旧的 2 秒激光、旧光束尺寸、缺失损伤状态/导弹生命周期契约会失败。
2. 用户确认清单中的蓝白 BOSS 能量弹调整版后，完成素材替换与代码修改。
3. `node --test tests/game-logic.test.mjs` 全部通过；内嵌脚本可解析，运行时引用的 PNG 均存在。
4. 尝试浏览器烟测：激光更粗更频繁；海面上蓝白能量弹清晰可辨；双方在两档损伤阈值出现对应烟火；导弹发射和飞行有声，消失后不残留音频节点。若 Chromium 仍在页面加载前 SIGTRAP，中止浏览器验收并如实报告。
