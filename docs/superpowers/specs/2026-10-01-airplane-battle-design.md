# 《飞机大战》网页游戏设计规格

## 1. 产品定位

- 面向小学四年级小朋友的简单射击游戏。
- 交付为单个 HTML 文件，不使用框架或外部依赖，双击即可游玩。
- 主要面向电脑浏览器，画面为 16:9 横屏并自适应窗口。
- 鼠标移动控制飞机，操作轻量，规则反馈清晰。

## 2. 视觉方向

- 原创 2.5D 卡通立体风格，参考《口算战争》的儿童友好和精致闯关气质，不复制其角色、素材或界面布局。
- 通过渐变、高光、柔边阴影、透视和粒子制造立体感，不引入真实 3D 引擎。
- 使用明亮蓝天、绿地与鲜艳玩具感 HUD，角色圆润可爱。
- 玩家战斗机约占画面宽度 8%，普通敌人与之接近或更小，保留足够躲避空间。
- 双列火球紧贴机身中轴发射，间距紧密。

## 3. 核心游戏循环

1. 鼠标在画布中移动，战斗机跟随鼠标，但不能离开战场。
2. 战斗机始终自动发射双列火球。
3. 玩家攻击、躲避怪物，获得经验并累计击杀数。
4. 每击杀 10 只普通怪物，暂停普通刷怪并出现 1 只 BOSS。
   - 场上同时最多存在 10 只普通怪物。
   - 逃离画面的怪物不计入击杀数，必须实际击杀满 10 只才触发 BOSS。
5. 击杀 BOSS 获得经验与随机飞机碎片，然后恢复普通战斗。
6. 飞机生命归零后结束本局，显示击杀、BOSS 数、等级和得分，允许重新开始。

## 4. 玩家飞机与基础武器

- 初始生命值：100。
- 双列火球初始每发伤害：2。
- 每击杀 1 只普通怪物获得 5 经验。
- 每击杀 1 只 BOSS，获得该 BOSS 初始生命值等量的经验。
- 经验达到 50 时，HUD 显示醒目的“攻击升级”按钮。
- “攻击升级”按钮固定在画面底部中央，便于点击且不与左侧碎片、右侧武器控件重叠。
- 点击“攻击升级”消耗 50 经验，将双列火球每发伤害永久翻倍。
- 经验可继续累积，只在玩家主动点击升级时扣除。

## 5. 普通敌人

### 5.1 俯冲利爪老鹰

- 生命值：20。
- 行为：先在空中盘旋锁定，再收翼俯冲。
- 攻击：用爪子近战，命中飞机造成 10 伤害。
- 视觉：展翼、前伸利爪、带速度线。

### 5.2 独眼俯冲无人机

- 生命值：30。
- 行为：锁定飞机后俯冲追踪。
- 攻击：接触后自爆并消失，造成 30 伤害。
- 视觉：倾斜机身、中央锁定独眼、自爆前红灯加速闪烁。

### 5.3 蝙蝠独眼怪

- 生命值：10。
- 行为：快速接近并贴住飞机。
- 攻击：贴住期间每秒造成 10 伤害。

### 5.4 乘杖飞行魔法师

- 生命值：50。
- 行为：披着斗篷，斜坐魔法杖飞行，与玩家保持一定距离。
- 攻击：发射追向玩家的魔法火球，每发造成 30 伤害。
- 魔法火球可被玩家的任意武器击爆。
- 视觉：斗篷迎风鼓起，帽檐跳动，挥手聚集魔法球。

## 6. BOSS

- 每次随机出现棕色战斗机或蓝色战斗机。
- 棕色 BOSS：厚重宽翼和红色双炮，使用扇形弹幕与低速冲撞。
- 蓝色 BOSS：尖长机首、后掠翼和蓝色能量炮，高速横移并发射交叉弹幕。
- BOSS 生命值按出现序号每 5 只一组，每组的上下限都增加 10：
  - 第 1–5 只：50–100。
  - 第 6–10 只：60–110。
  - 第 11–15 只：70–120。
  - 后续依此类推，不封顶。
- BOSS 登场时显示名称和独立大血条。

## 7. 碰撞与受伤

- 子弹与目标、敌人与玩家、魔法火球与玩家或玩家子弹之间进行碰撞判定。
- 瞬时碰撞伤害后给玩家短暂无敌时间，防止单次接触重复扣血。
- 蝙蝠的持续伤害单独按时间累计，不受瞬时碰撞无敌规则影响。

## 8. 飞机碎片与特殊武器

- 每击杀 1 只 BOSS，随机获得 1 枚“追踪弹碎片”或“激光碎片”。
- HUD 同时显示两种碎片数量，例如“追踪弹 3/5”与“激光 5/5”。
- 同类碎片达到 5 枚时，立即暂停战斗并询问是否升级。
- 选择升级：消耗 5 枚对应碎片，首次解锁武器，之后提升武器等级。
- 选择暂不升级：碎片全部保留，HUD 显示“5/5 可升级”，玩家可以随时再次打开升级。
- 双列火球始终保留，特殊武器作为额外攻击。
- 追踪弹：自动锁定最近怪物或 BOSS。1 级每枚造成 200 伤害，每升1 级再增加 200 伤害。
- 激光枪：持续锁定飞机前方最近怪物或 BOSS。1 级每秒造成 150 伤害，每升1 级再增加每秒 150 伤害。
- 两种特殊武器都解锁后，同一时间只激活其中一种。
- 玩家可点击 HUD 的武器图标随时切换，切换不消耗经验或碎片。

## 9. 界面状态

1. 开始页：游戏名称、鼠标操作提示、开始按钮。
2. 游戏中：战场与 HUD。
3. BOSS 战：清理普通怪物并显示 BOSS 名称、序号和血条。
4. 碎片升级弹窗：暂停战斗，提供“立即升级”与“暂不升级”。
5. 游戏结束：本局统计与重新开始按钮。

## 10. 技术结构

- HTML 界面负责开始页、HUD、升级弹窗与结束统计。
- Canvas 负责战场、飞机、怪物、子弹、粒子和碰撞反馈。
- JavaScript 使用 requestAnimationFrame 运行游戏循环，使用帧间隔计算移动与每秒伤害。
- 清理离开画面或已销毁的子弹、敌人和粒子，限制同时特效数量。
- 窗口尺寸变化时保持 16:9 比例并重算鼠标坐标。
- 鼠标离开战场时，飞机停在当前位置。
- 飞机坐标直接同步到鼠标在画布内的逻辑坐标，不使用滞后缓动。
- 使用 Web Audio API 在单 HTML 内合成火球、命中、爆炸、受伤、升级和 BOSS 登场声效，不加载外部音频文件，不提供静音按钮。
- 所有声效在首次使用时合成为 AudioBuffer 并缓存，高频火球与命中声应进行节流。
- 飞机、怪物、BOSS、火球、导弹和地面景物在启动时预渲染为缓存精灵，主循环不重复创建其渐变和阴影。
- 地面使用不超过 12 个树木、草丛或湖泊精灵进行视差滚动，距离越近移动越快。
- 鼠标监听范围覆盖整个游戏区域，包括 HUD 和按钮上方；飞机保持完整显示，不进入画布边缘的裁切区域。
- 追踪武器在 HUD 与战场中统一使用带头锥、弹体、尾翼和尾焰的导弹造型。

## 11. 难度曲线

- 随本局游戏时间逐步缩短普通怪物的生成间隔。
- 不额外改变已明确规定的怪物生命值与单次攻击伤害。
- 具体生成间隔、移动速度和发射频率在实玩验证中调整，以“初次游玩可存活并见到第一只 BOSS”为基准。

## 12. 验证与完成标准

- 在实现前先编写可直接在浏览器中运行的规则测试。
- 测试覆盖：怪物伤害、击杀经验、双列火球翻倍、BOSS 生命范围、碎片保留与消耗、特殊武器等级伤害。
- 浏览器实玩验证：鼠标移动、边界限制、自动发射、所有碰撞、BOSS 切换、升级暂停、武器切换、游戏结束、重新开始和窗口缩放。
- 检查浏览器控制台无错误，主流桌面浏览器中操作流畅。
- 最终交付只包含必要的单 HTML 游戏文件与设计/计划文档，不引入无关功能。

## 13. 项目文档与版本机制

- 所有设计、计划、使用说明与变更记录都保存在本项目目录内，便于后续创建 GitHub 仓库。
- `index.html` 始终保持为当前最新可玩版本，作为 GitHub Pages 默认入口。
- `versions/airplane-battle-v1.html`、`versions/airplane-battle-v2.html` 等文件保存每个已发布版本的完整单文件快照，新版本不覆盖旧快照。
- `docs/CHANGELOG.md` 记录每个版本的玩法、视觉与修复变化。
- `README.md` 说明游戏操作、本地运行、版本目录和 GitHub Pages 入口。
- 开始页与游戏 HUD 显示当前版本号。
