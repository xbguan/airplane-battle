# 飞机大战像素 UI 与无缝背景设计

## 目标

把开始、结算、战斗 HUD 和武器操作区统一为已确认的儿童向 2.5D 卡通像素风；移除游戏画面右上角的名称/版本；修复炮口闪光错位与背景拼贴硬边。

## 弹框与文字

- 开始出击与再来一局弹框缩小约 25%，保留深蓝金属面板、浅蓝描边与橙色主按钮。
- 弹框主视觉使用既有 `assets/characters/player-fighter.png`，不再用 CSS 或 emoji 飞机替代。
- 游戏名称和版本只在这两个弹框内以小号“飞机大战 · V2.2”显示；主游戏画面不再显示名称或版本。
- 所有弹框标题、说明和按钮使用本地 CSS 模拟像素字：等宽字形、阶梯式深色文字投影和短字距。项目不引入外部字体或 CDN。

## HUD 与武器区

- 左生命、中进度、右经验保留原位置和数值规则，仅优化为紧凑的像素金属仪表。
- 追踪弹碎片与激光碎片按钮分别使用既有 `fragment-homing.png`、`fragment-laser.png`，保留数量 `x/5`。
- 攻击升级按钮使用新增的透明 PNG“炮弹加上箭头”图标；费用和攻击等级规则不变。
- 右下三格使用独立透明 PNG：双列机枪、追踪导弹、激光发射器。等级文字仍由 DOM 更新；锁定、可用、已选择状态只改变边框、亮度和上浮，不改变伤害或冷却。

## 机枪表现

- 新增透明背景的黄白四角像素炮口火花，替换现有错误裁切的 `player-muzzle-flash.png`。
- 火花锚定在玩家战机两侧枪管的末端，尺寸小于枪管间距，只在开火帧出现约 0.06 秒。
- 机枪音效为缓存的低沉短促像素“哒、哒、哒”，每发约 0.09 秒；不在每一帧创建音频节点。

## 无缝背景

- 两种背景均以各自的水面循环 PNG 作为全屏连续底层。
- 原本带圆角/矩形的地形区块停止直接绘制；改为透明边缘的独立岛屿、峡谷、云雾景观层。
- 景观层按预设的非对称序列、不同纵向速度与随机起始偏移循环。所有景观边缘保持透明或水面过渡，因此不会露出矩形硬边；同一景观不会相邻重复。
- 俯视与斜视仍由开始弹框选择，均保留，不改变场景选择规则。

## 新增素材与资产清单

新增透明 PNG 并预加载缓存：

- `assets/weapons/player-muzzle-flash-v2.png`
- `assets/weapons/ui-attack-upgrade.png`
- `assets/weapons/ui-machinegun.png`
- `assets/weapons/ui-homing-missile.png`
- `assets/weapons/ui-laser-cannon.png`
- 俯视、斜视各自的透明岛屿/峡谷景观层与云雾层。

每项新增文件必须列入 `全部资产清单.html` 的既有“武器与道具”或“景观图块”分组，提供缩略图、路径和用途。可动武器/UI 物件使用透明背景；场景图块不混入角色或 HUD。

## 验收

- 主游戏画面没有名称和版本，两个弹框内各有小号像素文字“飞机大战 · V2.2”。
- 开始弹框使用玩家战机 PNG；无 emoji 作为图标或主视觉。
- 炮口火花位于两支枪管末端，开火时为短暂火花；机枪播放短促“哒哒哒”。
- 碎片、攻击升级和三种武器格均有相应像素 PNG。
- 两种背景连续滚动时无矩形贴片、硬边或相邻重复景观。
- 不改变战斗数值、碎片、升级、武器冷却、缓存或性能上限。
- 新增规则测试先失败后通过；`node --test tests/game-logic.test.mjs`、内嵌脚本语法检查和资源路径检查通过；浏览器烟测通过或明确报告环境阻断。
