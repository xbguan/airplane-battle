# 飞机大战 UI、碰撞与激光反馈设计

## 目标

将开始/结算 UI、HUD 与战斗特效统一到现有精致 2.5D 卡通像素风，同时修复普通怪撞机结算与魔法师碰撞遗漏。

## 视觉与交互

- 开始页与结算页采用深蓝金属描边、像素铆钉、玻璃质感仪表和橙色主按钮；不再沿用 V1 奶油白弹框。
- 开始页提供俯视河谷（默认）和斜视峡谷两张背景选择卡。选择仅影响当前局，开始游戏前写入 `activeSceneBackground`；两张背景始终预加载。
- HUD 保持左生命、中进度、右经验、下方升级与武器区的布局，替换 emoji 为 CSS 像素图标，使用金属框、玻璃槽和立体填充条。
- 机枪炮口闪光缩至约 10×12 逻辑像素，贴合战机两侧枪管口。机枪音效为缓存的短促连发，不高频创建 AudioNode。

## 战斗规则

- 猫头鹰、无人机、蝙蝠、魔法师与玩家发生机体碰撞时：玩家承受该类型原有伤害；普通怪立即通过 `killEnemy` 结算，因此计入 `0/10` 和既有 5 经验。
- 蝙蝠的贴身持续伤害改为一次撞击伤害 `10` 后死亡；魔法师补上原本缺失的机体碰撞判定，伤害为其既有 `30`。
- BOSS 碰撞维持原有只伤害玩家的规则，不计作击杀。
- 激光保持每 2 秒结算伤害。充能期间只显示锁定标记；到时产生约 0.14 秒的一次性射线、命中特效和音效，之后消失，不再持续粘连目标。
- 仅现有远程攻击加入发射音：魔法师魔法脉冲、橙 BOSS 炮击、蓝 BOSS 电弧；不为猫头鹰、无人机、蝙蝠增加远程攻击。

## 验收

- 选择任一背景后进入游戏，画面使用所选背景组合。
- 四种普通怪撞机后均扣血、死亡、增加普通击杀进度与经验；BOSS 不死亡。
- 激光仅在 2 秒结算点短暂出现，命中伤害次数不变。
- HUD、开始页和结算页不再使用 emoji；机枪闪光贴枪管；已有远程角色有相应发射音。
- `node --test tests/game-logic.test.mjs` 通过；所有 `AssetManifest` 路径存在。
