# 《飞机大战》HUD 清晰度与机枪对齐设计

## 目标

在不改变伤害、射速、碰撞、升级、碎片和武器规则的前提下，解决顶部进度图标含义不清、碎片控件模糊、攻击升级按钮过大，以及玩家机枪火花和弹道未对齐枪眼的问题。

## HUD 调整

- 顶部“本轮进度”左侧现有黄色水滴形 CSS 图标没有明确语义，改为小尺寸“靶心怪物眼”图标，表达普通怪物击杀进度；不使用 emoji，不新增图片资源。
- 追踪碎片改用既有 `ui-homing-missile.png`，激光碎片改用既有 `ui-laser-cannon.png`。两张 UI 图标主体饱满，避免现有碎片素材透明留白过大导致缩小后不可辨。
- 碎片名称与数量取消双层深色投影，使用清晰的深蓝实色文字；按钮立体感继续由边框、背景和外阴影承担。
- 攻击升级按钮保留底部中央位置、现有图标、费用和当前伤害文字，但设置独立的紧凑图标尺寸、内边距和字号，不再继承武器格图片的 `65%` 尺寸规则。

## 玩家机枪对齐

- 玩家战机 PNG 的有效图形横向偏离图片画布中心。仅在玩家战机绘制时补偿该偏移，使战机主体与玩家坐标、碰撞圆和投影重新居中；不修改原素材文件。
- 两侧枪口采用一组共享横向锚点。`firePlayer()` 的子弹、`drawPlayer()` 的炮口火花都读取同一组横坐标，避免后续分别调整再次错位。
- 子弹初始纵坐标、速度、伤害、半径、射速和曳光长度保持不变；现有曳光尾端继续连接枪口，只修正横向轨迹。
- 炮口火花保持短暂出现和现有 8×8 逻辑像素尺寸，位置贴近两侧橙色枪管顶端。

## 文件范围

- 修改 `index.html`：HUD 样式、碎片图标引用、玩家绘制补偿和共享枪口坐标。
- 修改 `tests/game-logic.test.mjs`：增加 HUD 清晰度、紧凑按钮和统一枪口锚点的静态/规则契约。
- 必要时修改 `tests/browser-smoke.py`：增加按钮尺寸与可见布局检查，不改变其他烟测场景。
- 更新 `docs/CHANGELOG.md`。
- 不修改 PNG，不同步 V1，不执行 Git 操作。

## 测试与验收

1. 先增加测试并确认因当前水滴图标、旧碎片图片、通用大图规则和分离枪口坐标而失败。
2. 最小修改后运行 `node --test tests/game-logic.test.mjs`，确认全部通过。
3. 校验内嵌 JavaScript 语法和所有引用资源存在。
4. 使用 `tests/browser-smoke.py` 与本地 HTTP 服务验证：画布持续动画、无控制台错误；攻击升级按钮不遮挡战机或左右 HUD；碎片文字和图标可辨；左右火花、弹芯和曳光位于对应枪眼纵线上。
5. 若本机 Chromium 仍在页面加载前因 `SIGTRAP` 中断，保留静态与规则验证结果并明确报告浏览器验证未完成。
