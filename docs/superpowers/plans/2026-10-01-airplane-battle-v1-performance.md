# 飞机大战 V1 性能与地景优化计划

## 根因

- 火球每 0.19 秒射击一轮，每次声效都新建振荡器和增益节点，命中声还会继续叠加节点创建。
- 飞机、怪物、BOSS 和每枚火球在每帧重新创建渐变与阴影，长时间战斗会引起频繁内存分配。
- 鼠标事件仅绑定 Canvas，鼠标进入 HUD 时飞机不再接收新坐标。

## 实施

1. 在 Playwright 测试中记录声效声源数、Canvas 渐变创建次数、HUD 区域鼠标跟随和飞机边界，确认修改前失败。
2. 将声效预合成为 AudioBuffer，播放时仅创建轻量 BufferSource，火球声最少间隔 360ms。
3. 将所有高频角色与子弹预渲染到隐藏 Canvas，主循环改用 `drawImage`。
4. 绘制树木、草丛和湖泊精灵，保持 12 个地景对象循环使用，以景深调整移动速度与大小。
5. 将鼠标事件上移到 `#game-shell`，并将飞机边界缩进 105 逻辑像素。
6. 用 CSS 构建 HUD 导弹图标，Canvas 追踪弹同步使用预渲染导弹精灵。
7. 运行 Node 规则测试、语法检查、离线检查和 Playwright 浏览器性能回归，然后更新 V1 快照。
