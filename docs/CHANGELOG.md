# 版本记录

## V2.2（开发中）- 2026-10-02

- 新增两张完整本地纯场景背景：自然不对称的斜视峡谷与近 90° 俯视河谷；当前使用俯视河谷，斜视峡谷已预加载保留，等待用户指令切换。
- 背景改为两张同宽长图纵向首尾循环，移除与完整场景冲突的旧 Canvas 树木前景。
- 新增《全部资产清单》可读规则页，逐项列出角色、武器与道具、独立投影、景观及两套完整背景，并记录素材分层与运行约束。

## V2.1 - 2026-10-02

- 飞机、普通敌人、双 BOSS、机枪弹、追踪导弹和激光统一为圆润 2.5D 像素精灵，保留立体像素高光与侧面。
- BOSS 每次掉落 2 枚碎片，优先补给等级较低的未满级特殊武器；同等级时随机选择。
- 修复蓝色 BOSS 在摆动低于入场线时错误重入场、造成跳动的问题。

## V2 - 2026-10-01

- 将火球、追踪导弹和激光改为有限等级，避免后期无限叠加伤害。
- 普通怪与 BOSS 随已击败 BOSS 数逐阶段成长，形成前易后难的战斗曲线。
- 激光改为每 2 秒结算一次伤害，追踪导弹最短发射间隔改为 1.5 秒。
- 满级武器不再获得对应碎片；两种特殊武器均满级后，BOSS 不再掉落碎片。

## V1 - 2026-10-01

- 完成单 HTML、16:9 自适应的飞机大战。
- 完成鼠标跟随、双列火球和飞机生命值。
- 完成俯冲利爪老鹰、独眼俯冲无人机、蝙蝠独眼怪与乘杖飞行魔法师。
- 完成棕色“大地重锤”和蓝色“蓝色闪电”BOSS。
- 完成普通怪物、BOSS 经验奖励与火球攻击翻倍。
- 完成飞机碎片、延后升级、追踪弹、激光枪与武器切换。
- 完成魔法火球击爆、碰撞无敌、受伤反馈、粒子与震屏效果。
- 完成开始页、HUD、BOSS 血条、升级弹窗和结束统计。
- 优化每局普通怪物数量：场上同时最多 10 只，击杀满 10 只后进入 BOSS 战。
- 增加内置 Web Audio 声效，无外部音频依赖。
- 取消飞机追赶鼠标的缓动延迟，并降低 HUD 更新频率、缓存背景渐变、收紧粒子上限。
- 将“攻击升级”按钮移到画面底部中央，避免遮挡战斗视野。
- 将声效从高频创建振荡器改为一次合成的 AudioBuffer 缓存，降低火球声触发频率。
- 将飞机、怪物、BOSS、火球和导弹预渲染为缓存精灵，避免每帧重新创建大量渐变和阴影。
- 鼠标跟随改为监听整个游戏区域，即使鼠标位于 HUD 控件上方，飞机也会继续跟随。
- 增加缓存树木、草丛和湖泊，以少量精灵进行景深视差移动。
- 追踪武器 HUD 图标改为立体导弹造型，并让 Canvas 中的追踪弹使用同类造型。
- 收紧飞机边界，避免鼠标靠近画布边缘时机身被裁切。
- UI：采用“甜酷野战 × 小小战斗队员”视觉，优化奶油白 HUD、橙色升级按钮、装备格、面板与缓存角色精灵，不改变玩法规则。
